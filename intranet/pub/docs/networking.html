TERMINAL NETWORKING NOTES
=========================

A terminal connection usually has three stages:

  1. CONNECT
     Establish a TCP or simulated modem connection.

  2. INTERACT
     Read the remote prompt and send commands.

  3. DISCONNECT
     Exit the remote service and return to the local system.

Useful terms:
  HOST        remote computer or service
  PORT        numbered network endpoint
  TELNET      traditional interactive terminal protocol/client
  NETCAT      simple TCP client, often invoked as nc
  LYNX        text-mode web browser

External systems can be slow or unavailable. If a connection appears stuck,
return to the local service and try another destination.
