CP/M QUICK REFERENCE
====================

CP/M is an early microcomputer operating system.

Typical prompt:
  A>

Drive selection:
  A:
  B:

Useful conventions:
  DIR           directory listing
  program       run a .COM program by name
  program.ext   some commands may also accept an extension

The WarGames terminal imitates CP/M behaviour but is implemented as a modern
native program for reliability.
