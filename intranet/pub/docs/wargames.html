WARGAMES BACKGROUND
===================

This simulator recreates a fictional sequence inspired by the 1983 film
WarGames.

A computer user operating through an IMSAI-style terminal discovers remote
systems by dialling telephone numbers and listening for carrier tones.
One discovered machine is WOPR: the War Operation Plan Response computer.

Useful names and concepts:
  JOSHUA                  The name associated with the WOPR interface
  PROFESSOR FALKEN        The identity WOPR expects after successful access
  GLOBAL THERMONUCLEAR WAR
                          One of WOPR's strategic simulations
  TICTACTOE               A simple game that later becomes important

Treat the simulator as an interactive story. Read prompts carefully and
use HELP or LIST GAMES where offered.
