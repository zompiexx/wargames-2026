TELEHACK STARTER GUIDE
======================

Telehack is an external retro-computing service accessed through a terminal
connection.

From the WarGames environment, select ARPANET from the discovered systems
list. The connection script will use telnet when available, or netcat as a
fallback.

Once connected:
  read the remote prompt carefully;
  use HELP if offered;
  expect commands to differ from the local IMSAI terminal.

If the remote service disconnects, you should return to the WarGames
discovered-systems list.
