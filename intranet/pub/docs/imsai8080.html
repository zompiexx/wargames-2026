IMSAI 8080 TERMINAL QUICK GUIDE
===============================

The terminal presents a CP/M-style command prompt.

Common commands:
  DIR          list files/programs
  CLS          clear the screen
  DIALER       run the telephone dialler
  KERMIT       enter the communications program
  A:           select drive A
  B:           select drive B
  BYE          leave the terminal

The simulator is intentionally old-fashioned. Commands are generally short,
and many programs expect a single letter or a word followed by ENTER.
