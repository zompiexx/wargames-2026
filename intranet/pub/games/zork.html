ZORK ADVENTURER'S NOTES
=======================

Useful command forms:
  LOOK
  INVENTORY
  NORTH / SOUTH / EAST / WEST
  UP / DOWN
  TAKE object
  DROP object
  OPEN object
  EXAMINE object

Zork rewards careful observation. Read each room description, keep track of
exits, and avoid issuing several speculative commands at once.
